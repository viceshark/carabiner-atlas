# Атлас карабинов

Прототип справочника по типам карабинов для скалолазания, альпинизма, промальпа и спасработ. Интерфейс на русском и английском, переключение в шапке.

## Что внутри

- 14 типов карабинов в четырёх группах: форма корпуса, тип защёлки, блокировка, специальные.
- 24 популярные модели (Petzl, Black Diamond, DMM, CAMP, Wild Country, Kong) с характеристиками производителя и описанием применения по сферам.
- 9 страниц характеристик: что значит, как измеряют, на что влияет, график по всем моделям.

## Как открыть

Откройте `carabiner-atlas.html` в браузере. Или запустите локальный сервер в папке проекта:

```bash
python3 -m http.server 8000
```

и откройте http://localhost:8000/carabiner-atlas.html

## Как устроено

Одна HTML-страница без сборки и зависимостей. Шрифты подключены с Google Fonts: Unbounded, Golos Text, JetBrains Mono.

Навигация через hash:

| Адрес | Страница |
|---|---|
| `#` | главная с плитками типов |
| `#type-<id>` | тип карабина, например `#type-hms` |
| `#m-<id>` | модель, например `#m-petzl-attache` |
| `#spec-<id>` | характеристика, например `#spec-major` |
| `#specs` | список характеристик |

Все данные лежат в блоке `<script>`:

- `TYPES` — типы карабинов, их описания и списки моделей;
- `MODELS` — модели с характеристиками, источником и применением;
- `SPECS` — тексты страниц характеристик;
- `STANDARDS` — стандарты сертификации;
- `UI` — строки интерфейса на двух языках.

Чтобы добавить модель, добавьте объект в `MODELS` и её `id` в поле `models` нужных типов в `TYPES`.

Файл написан в формате Claude Artifact: без `<!doctype>`, `<html>`, `<head>` и `<body>`, эту обёртку добавляет платформа при публикации. Браузер открывает такой файл и без неё.

## Данные

Характеристики взяты с сайтов производителей и крупных магазинов снаряжения в октябре 2026 года. Где источники расходятся, указано меньшее значение прочности. Тип носика указан только там, где его подтверждает производитель.

Это прототип. Перед использованием снаряжения сверяйте маркировку на карабине и инструкцию производителя.
