# Атлас карабинов

Прототип справочника по типам карабинов для скалолазания, альпинизма, промальпа и спасработ. Интерфейс на русском и английском, переключение в шапке.

## Что внутри

- 16 типов карабинов в четырёх группах: форма корпуса, тип защёлки, блокировка, специальные (в том числе карабины с роликом и со шпорой).
- 36 моделей восьми брендов (Black Diamond, CAMP, DMM, Kong, Mammut, Petzl, Salewa, Wild Country) с характеристиками производителя и описанием применения по сферам.
- Фильтры на главной: по сфере применения, по бренду и поиск.
- 9 страниц характеристик: что значит, как измеряют, на что влияет, график по всем моделям.
- Калькулятор срыва: сила на карабине при заданном весе, высоте срыва и длине верёвки, а также высота и вес, при которых карабин сломается вдоль спинки, поперёк и с открытой защёлкой.
- Калькулятор износа: по времени использования, спускам, срывам, условиям и результатам осмотра оценивает нагрузку на рабочую поверхность, подсказывает, как часто проверять канавку, и говорит, не пора ли списать карабин.
- У каждого параметра калькуляторов есть подсказка (кнопка «?»).

## Запуск в Docker

```bash
docker compose up --build -d
```

Атлас откроется на http://localhost:8090. Другой порт задаётся переменной `ATLAS_PORT`, например `ATLAS_PORT=9000 docker compose up --build -d`. 

Без Compose:

```bash
docker build -t carabiner-atlas .
```

Образ основан на `nginx:1.27-alpine`. При сборке страница оборачивается в полноценный HTML-документ и отдаётся как `index.html`.

## Деплой: образ из GitHub, запуск на сервере

При каждом пуше в `main` GitHub Actions (`.github/workflows/docker-image.yml`) собирает образ для `linux/amd64` и `linux/arm64` и публикует его в GitHub Container Registry:

| Тег | Когда появляется |
|---|---|
| `ghcr.io/viceshark/carabiner-atlas:latest` | последний коммит в `main` |
| `ghcr.io/viceshark/carabiner-atlas:sha-<коммит>` | каждая сборка, для отката |
| `ghcr.io/viceshark/carabiner-atlas:1.2.0` | пуш тега `v1.2.0` |

Собрать заново без нового коммита можно кнопкой Run workflow на вкладке Actions.

**Доступ к образу.** Новый пакет в GHCR может оказаться приватным, даже если репозиторий публичный. После первой сборки откройте страницу пакета (профиль на GitHub → Packages → carabiner-atlas → Package settings) и выберите один из вариантов:

- сделать пакет публичным (Change visibility → Public): тогда на сервере логин не нужен;
- оставить приватным и один раз войти на сервере токеном с правом `read:packages`:

```bash
echo "<токен>" | docker login ghcr.io -u viceshark --password-stdin
```

**На сервере** нужен только файл `deploy/compose.yaml`, исходники не нужны. Скопируйте его в папку на сервере, например `~/carabiner-atlas/compose.yaml`, и выполните в этой папке:

```bash
docker compose pull && docker compose up -d
```

Атлас будет на порту 8090. Порт и тег задаются переменными `ATLAS_PORT` и `ATLAS_TAG`, например в файле `.env` рядом с `compose.yaml`:

```
ATLAS_PORT=80
ATLAS_TAG=latest
```

Обновление после нового пуша в `main` — та же команда `docker compose pull && docker compose up -d`. Откат: укажите в `ATLAS_TAG` нужный `sha-<коммит>` и выполните её же.

## Как открыть без Docker

Откройте `carabiner-atlas.html` в браузере. Или запустите локальный сервер в папке проекта:

```bash
python3 -m http.server 8000
```

и откройте http://localhost:8000/carabiner-atlas.html

## Как устроено

Одна HTML-страница без сборки и зависимостей. Шрифты подключены с Google Fonts: Unbounded, Golos Text, JetBrains Mono.

Навигация через hash:

| Адрес | Страница |
|---|---|
| `#` | главная с плитками типов |
| `#type-<id>` | тип карабина, например `#type-hms` |
| `#m-<id>` | модель, например `#m-petzl-attache` |
| `#spec-<id>` | характеристика, например `#spec-major` |
| `#specs` | список характеристик |
| `#calc` | калькулятор срыва |
| `#wear` | калькулятор износа |

Все данные лежат в блоке `<script>`:

- `TYPES` — типы карабинов, их описания и списки моделей;
- `MODELS` — модели с характеристиками, источником и применением;
- `SPECS` — тексты страниц характеристик;
- `STANDARDS` — стандарты сертификации;
- `UI` — строки интерфейса на двух языках.

Чтобы добавить модель, добавьте объект в `MODELS` и её `id` в поле `models` нужных типов в `TYPES`.

Файл написан в формате Claude Artifact: без `<!doctype>`, `<html>`, `<head>` и `<body>`, эту обёртку добавляет платформа при публикации. Браузер открывает такой файл и без неё.

## Данные

Характеристики взяты с сайтов производителей, а где производитель их не публикует, с сайтов крупных магазинов снаряжения (октябрь 2026). Где источники расходятся, указано меньшее значение прочности. Тип носика указан только там, где его подтверждает производитель.

Ссылки у моделей ведут только на сайты производителей. Если страницы у производителя больше нет (Petzl Freino M42), ссылки нет.

Калькулятор срыва — учебная модель: упругая верёвка, жёсткая страховка, коэффициент 1,66 для верхней точки. Реальные силы обычно ниже.

Калькулятор износа использует собственные поправки атласа (песок ×4, пыль и морской воздух ×1,5, сталь ×0,15, карабин без трения верёвки ×0,1); это не данные производителей. Вывод «списать» он делает только по результатам осмотра. Сроки службы взяты из FAQ Petzl: металл без ограничения, текстиль до 10 лет с даты производства.

Это прототип. Перед использованием снаряжения сверяйте маркировку на карабине и инструкцию производителя.
